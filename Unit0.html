The tidyverse

You may have noticed, and will see again, that Prof. Petchey sometimes does not load the packages ggplot2 or dplyr separately in his code – i.e. he doesn’t use library(ggplot2). Instead, you’ll see him use library(tidyverse).

The tidyverse add-on package is a convenience package: it loads several other packages at once, such as ggplot2, dplyr, readr, and tidyr. These loaded packages are associated with what’s termed “tidy” data, hence the tidyverse name.

There is no particular reason to use the tidyverse package other than convenience. If people have trouble using it, it’s fine to just load each library separately instead.

If you want to use library(tidyverse) you must first install the tidyverse package, using the Install Packages tool in RStudio, or with install.packages("tidyverse"). (Remember, you only need to install a package once.)

More information about the tidyverse is here.
