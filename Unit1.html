Practical

The aims of this first practical are that by the end of it you can:

  • use RStudio, both on the UZH RStudio Server (which you will use in the exam) and, if you wish, on your own laptop;
  • organise your work in an RStudio project, and install and load add-on packages;
  • get a data file into R;
  • find and fix errors in R code (everyone makes them, all the time!);
  • know what previous knowledge is expected, and which parts of it you need to revise.

Work through the parts in order. Don’t worry if you don’t finish everything in the practical session: finish at home, and ask on the Discussion Forum if you get stuck.

Part 2: An RStudio project and add-on packages (about 15 minutes)

Make an RStudio project for BIO144. An RStudio project is a folder that holds everything for one piece of work (scripts, data, results), and that RStudio remembers. When you open the project, R automatically looks for files in that folder, so reading data files “just works”.

In RStudio: File > New Project… > New Directory > New Project. Name it BIO144 and choose where to put it. RStudio will restart in the new project (you will see “BIO144” at the top right). Do this wherever you will work (on RStudio Server, and on your laptop if you use it). Each time you work on BIO144, open this project first (File > Open Project…, or the menu at the top right).

Install the add-on packages we will use. In the console, run:

install.packages("tidyverse")

This installs a set of packages, including readr, dplyr, tidyr and ggplot2. It can take a few minutes. (On RStudio Server they may already be installed.) Then load them with:

library(tidyverse)

Part 3: Get the data into R (about 15 minutes)

In the lecture you recorded your reaction times. The class data are in a file called reaction_times_2027.csv. Download the file into your project folder by running this line in the console (with your BIO144 project open):

download.file("https://raw.githubusercontent.com/opetchey/BIO144_Practicals_WAs/refs/heads/main/assets/datasets/reaction_times_2027.csv",
              destfile = "reaction_times_2027.csv")

Look in the Files pane: you should see the file in your project folder. (You can also click on it and choose “View File” to see what’s inside. But do not open it in Excel and save it: Excel can change data in ways that cause problems for R.)

Now open a new script, save it in the project folder (e.g. as unit1_practice.R), and write and run:

library(readr)
class_RTs <- read_csv("reaction_times_2027.csv")
class_RTs
str(class_RTs)
summary(class_RTs)

How many rows (participants) and columns (variables) are there? Does that make sense? Are the reaction times numbers (<dbl>) and is sex at birth text (<chr>)?

Part 4: Fix the reaction time script (about 40 minutes)

We give you a script that does a version of the analysis from the lecture’s live demonstration: it reads in the class data, tidies it, makes some graphs, and does a t-test comparing the reaction times of females and males. But the script contains about ten deliberate errors. Your task is to find and fix them, so that the script runs from top to bottom.

Some of the code uses functions from the dplyr, tidyr and ggplot2 packages. You will learn how these work in Unit 2. For now, read the comments in the script to see what each step does. You do not need to understand how these functions work to fix the errors: they are the kinds of mistakes everyone makes (typos, a missing comma or bracket, and so on).

Download the script into your project folder:

download.file("https://raw.githubusercontent.com/opetchey/BIO144_Practicals_WAs/refs/heads/main/assets/scripts/reaction_time_analysis_needs_fixing.r",
              destfile = "reaction_time_analysis_needs_fixing.r")

Open it from the Files pane. Then run it one command at a time from the top (Ctrl/Cmd+Enter runs the current line, or the whole command if it spans several lines). After each one, look at the console. If there is an error, fix it, and run that line again before moving on.

How to read an error message. The message is R telling you what it could not do. Read it carefully, and look for names you recognise. Here is what some common messages usually mean:

Error message (part of it) Usual cause What to check
could not find function "xyz" Typo in the function name, or the package containing the function is not loaded Spelling; a library() line for the package
object 'xyz' not found Typo in the name of an object, or the object was never created (perhaps because an earlier line failed) Spelling and capital letters; did the line that creates it run without error?
... does not exist in current working directory Wrong file name, or the file is not in the project folder The Files pane
unexpected string constant, unexpected symbol, unexpected ')' Missing or extra comma, bracket or quote The line, and the one before it
Column 'xyz' is not found Typo in a variable name (including capital letters) names() of the data
The console shows + instead of > R is waiting for you to finish the command: usually a missing closing bracket or quote Press Esc, then fix the line

There is more about this in the section Finding and fixing errors in Chapter 2 of the course book.

Watch out for errors that give no error message! At least one of the errors makes the code run without complaint, but does the wrong thing. Read the comments, and check that each step gives the result it should.

Using an AI assistant to understand an error. Choose one of the error messages you met. Paste the message (and the line of code) into an AI assistant and ask it to explain what the message means, rather than to fix the code for you. Compare its explanation with your own understanding and with the table above. Then fix the code yourself.

Finally, check the script is reproducible. When you have fixed all the errors: Session > Restart R, then run the whole script from the top (Code > Run Region > Run All). If it runs without any errors, from a fresh start, then it will give the same results every time, for you and for anyone you share it with.

If you got stuck, here is the corrected script. Please only look at it after trying to fix the errors yourself: reaction_time_analysis_working.r

If you finish early: change the code that makes the box plot, so that the axis labels are more informative (hint: add + labs(x = "Sex at birth", y = "Mean reaction time (ms)")). Or look at the t-test output: what is the estimated difference between the groups, and its 95% confidence interval? (We will look at reporting results in later units.)
